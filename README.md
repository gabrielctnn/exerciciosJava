# ☕ Exercícios de Java: Fundamentos

Este repositório foi criado para documentar meu progresso e aprendizado na linguagem **Java**. Aqui estão concentrados exercícios práticos cobrindo desde a sintaxe básica até estruturas de controle de fluxo.

---

## 🚀 O que estou praticando?

Nesta etapa do curso, o foco é consolidar a base da linguagem. Os exercícios abordam:

*   **Sintaxe e Variáveis:** Manipulação de tipos primitivos e declaração correta de variáveis.
*   **Operadores:** 
    *   Aritméticos (`+`, `-`, `*`, `/`, `%`)
    *   Lógicos (`&&`, `||`, `!`)
    *   Atribuição e Incremento (`+=`, `-=`, `++`, `--`)
*   **Estruturas Condicionais:** Tomada de decisão com `if`, `else if`, `else` e o operador ternário.
*   **Estruturas de Repetição:** Laços de iteração para automação de tarefas usando `while`, `do-while` e `for`.
