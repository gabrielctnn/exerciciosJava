# ☕ Exercícios de Java: Fundamentos

Este repositório foi criado para documentar meu progresso e aprendizado na linguagem **Java**. Aqui estão concentrados exercícios práticos cobrindo desde a sintaxe básica até estruturas de controle de fluxo e manipulação de dados.

---

## 🚀 O que estou praticando?

Nesta etapa, o foco é consolidar a base da linguagem e resolver problemas de lógica. Os tópicos abordados incluem:

* **Sintaxe e Variáveis:** Manipulação de tipos primitivos e declaração de variáveis.
* **Operadores:** Aritméticos, lógicos, atribuição e incremento.
* **Estruturas Condicionais:** Tomada de decisão com `if`, `else if`, `else`.
* **Manipulação de Strings:** Uso de métodos essenciais como `.trim()`, `.toUpperCase()`, `.isEmpty()` e `.length()`.
* **Entrada e Saída de Dados:** Leitura de dados com `Scanner` e exibição formatada com `printf` (controle de casas decimais e símbolos especiais).

---

## 📂 Organização do Repositório

### 📝 Exercícios de Prática (`src/ex...`)
Uma série de exercícios focados em fixar os conceitos básicos:
* **Ex1 ao Ex4:** Prática de operadores aritméticos e entrada de dados simples.
* **Ex5 ao Ex8:** Introdução a estruturas condicionais e cálculos matemáticos aplicados.

### 🏆 Desafios de Lógica (`src/Desafio.java`)
Problemas mais complexos que simulam situações reais:
* **Cálculo de Salário Líquido:** Um programa que recebe o salário bruto e bônus, aplica alíquotas de imposto proporcionais (5%, 10% e 15%) e retorna o valor final a ser transferido. 
    * *Destaque:* Uso de formatação `%.2f` para valores monetários.
* **Padronização de Projetos:** Validação de entradas para sistemas empresariais. O programa limpa espaços extras, converte o texto para maiúsculas e valida se a entrada é válida ou vazia.
